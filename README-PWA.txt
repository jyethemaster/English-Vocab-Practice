# English Word Trainer PWA

This folder is ready to upload to a GitHub repository and deploy with GitHub Pages.

## Files
- `index.html` — the app
- `manifest.webmanifest` — PWA installation information
- `sw.js` — service worker
- `icon-192.png` and `icon-512.png` — required Android/PWA icons

## GitHub Pages
Put all five files in the same folder, preferably the repository root.

Then enable:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`

After GitHub Pages deploys, open the HTTPS Pages URL in Chrome on Android.

If Chrome has previously opened an older version of this app, clear the site's data once before testing installation.
